# Resolução exercício Beecrowd1095

# Descrição do problema
O programa não possui dados de entrada e deve apenas exibir uma sequência impressa na tela de forma estrita. A variável `I` começa em 1 e aumenta de 3 em 3 a cada iteração. A variável `J` começa em 60 e diminui de 5 em 5. O loop se encerra quando `J` atinge o valor 0.

## Como Funciona
1. O algoritmo declara e inicializa a variável `i = 1`.
2. Uma estrutura de repetição `for` gerencia o comportamento de `j`, iniciando em 60 e decrementando de cinco em cinco unidades (`j -= 5`) enquanto `j >= 0`.
3. Dentro do laço, a cada execução, o programa imprime os valores atuais formatados como `I=x J=y`.
4. Logo após a impressão, a variável `i` recebe um incremento de três unidades (`i += 3`), acompanhando o passo definido pela lógica do problema.
